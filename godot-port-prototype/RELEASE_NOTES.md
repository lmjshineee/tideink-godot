# INKWAVE Godot Demo v0.3.0-preview.1

本次预览版升级为默认单机 5v5，新增 Kelpline 地图与地图选择，迁入原版四种角色外观、87 骨骼/蒙皮与四武器，并改进 HUD 和菜单。

- 一名玩家和九名机器人，两队各五人；保留 1v1 练习。团队敌我、最近命中、群体伤害、各自生命/保护重生和权威涂地计分接通；队友涂墨不奖励玩家个人点数或大招。
- Tidewater 与 Kelpline 原版几何、道具碰撞、可涂表面、计分格及场景装饰。机器人使用原版导航图和碰撞移动体，能执行步行/落差路线。
- 四种发型/肤色/服装及原版武器几何；基础骨骼步态、瞄准、后坐力、甩墨/投弹与发梢动作。
- 小地图、双方存活人数、击倒提示、Tab 十人名单、可点击开始/暂停/结果操作。保留上一版 FPS、界面缩放与鼠标灵敏度设置，并支持赛前配色/色盲、90/180 秒与武器选择。

验证：工作区和独立发布快照均 51/51；解析失败隔离用例、非默认跑速初始化、短时原生双地图 5v5/菜单/名单/设置缩放及既有键鼠七项流程通过。arm64 架构、签名、无界面及 12 帧原生应用启动通过；最终 PCK 双地图规则检查与 ZIP 解压后的签名/架构复核通过。

范围：单机预览版，音频和联机尚未迁入；角色材质/动作是 Godot 的重建版本，完整 IK、表情、舞蹈与战斗/屏幕特效未完成；机器人未启用跳跃边、完整潜墨/撤退/炸弹/大招策略。GUI 检查使用位置/保护与缩短等待条件，未完成人工完整 90/180 秒对局、持续帧率或温度验收。
