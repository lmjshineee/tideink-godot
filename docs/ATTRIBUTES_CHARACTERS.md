# 属性加点与人物差异 · preview.24

用户反馈三件装备能力没有对应服饰，要求直接加点并改变人物建模。本批移除三件／十二槽的产品流程，准备页点「属性 · 加点」打开「潮汐之镜」。头饰／衣服／鞋子不再被当作没有模型的能力容器；外观在人物预览下的「形象」按钮依次切换，另有随机形象。

## 属性分配

每局开始前有 20 个免费属性点，八项各 0—8 级，每级花 1 点，可减级返还、免费重置或 ROLL 分满 20 点。初始未分配时保留既有基线，界面明确显示可用点数、各级、实际数值和当前说明。整套配装 ROLL 包括属性；仅属性 ROLL 不改变武器／天赋／副武器。

参考 [Supergiant 的夜之镜设计](https://www.supergiantgames.com/blog/hades-hit-up-the-nighty-night-update/)，取可直接投资能力、形成不同配点的方向。本地固定预算、等级与公式不是 Hades 原作数值；本批不实现跨局货币、刷级或解锁树。

| 属性 | 8 级上限 | 实际效果 |
| --- | --- | --- |
| 生命上限 | +18% | 与天赋乘算；均衡 132 → 155.76 HP |
| 墨水容量 | +25% | 均衡 110 → 137.5 墨 |
| 奔跑速度 | +12% | 人形／干地墨形；保留射击、爬墙、技能限速 |
| 潜泳速度 | +12% | 己方墨地；敌墨潜游天赋原速保持 |
| 主武器省墨 | −18% | 八主武器实际主射／蓄力／甩墨／滚刷，副武器和护伞另行耗墨 |
| 回墨速度 | +20% | 自然回墨；等待和补给量保持 |
| 大招充能 | +15% | 实际有效新增涂地；重涂、墨墙与大招自身涂地仍无奖励 |
| 副武器冷却 | −15% | 新施放／开始的冷却；已有剩余时间保持 |

等级 `r` 限制到 0—8，收益为 `上限 × r/(r+4) ÷ (8/12)`；前几级收益明显，后续递减。伤害、射速与护盾不加点，当前较宽容基础伤害保持。生命专精能改变击倒门槛，满生命均衡最高 155.76 HP 可接住 150 的精准狙击；武器伤害没有增加。

编辑不回血、不补墨、不加充能、不清已有冷却；降低容量／生命会截断超出新上限的现值。开战与复活使用新上限。机器人按玩家实际已用点数得到相同预算，初次入场只生成一次；未花完 20 点也不能给机器人额外预算。属性、天赋整局固定，死亡和主副重摇保留；复活继续由玩家选点确认。

地图／规则／造型重载与结算重开保留本次会话分配，退出 App 后没有磁盘属性存档。

## 检查边界

`test_character_archetypes.py` 核对本地可重现生成、四套几何差异、原始节点／蒙皮／动作／材料／UV／索引和非角色网格不变；新 GLB 语义与原生画面先通过后，资源清单只追加四条。`check_character_archetypes.gd` 检查实际加载、八武器持握、有限骨骼姿态和墨形切换。旧角色检查按有意几何变形改为有界语义空间验证，仍核对表情、步态和脚部高度。

`check_attribute_allocation.gd` 验证非法／超预算／超等级／别名负例、200 次可复现 ROLL 和真实八属性路径。`verify_attribute_allocation.gd` 实际鼠标加减、Enter／Esc、两尺寸、造型／规则重载和省墨主射；`capture_archetypes.gd` 保留四人同队色的正面、侧面、背面、跑动、脸部与各八种持武器画面。

无界面规则、受控原生、自然自动对局与实际 App 导出分别记录；真人审美、配点平衡和长期性能／温度必须另行验收。完整证据进入 `render-evidence/attributes-characters-2026-10-09/`。
