# 墨仔伙伴与投放提示

2026-10-05。本批用户选择“战斗小伙伴，会追敌”；新增独立可选道具 `ink_buddy`，保留八武器专属大招和未消耗进度的死亡继承。

## 参考与改编

Nintendo 的 [Splatoon 3 发售介绍](https://splatoon.nintendo.com/en/news/fast-fun-and-frant-ink-action-awaits-in-splatoon-3-available-now/) 将 Smallfry 定位为故事模式帮手；[官方游戏页面](https://splatoon.nintendo.com/en/) 介绍可把它扔向敌人和物体。[官方武器入门](https://splatoon.nintendo.com/en/news/beginner-basics-for-splatoon-3-choosing-the-right-weapons/) 介绍 Autobomb 等副武器的压制和寻找敌人用途。

本项目把可投掷伙伴与近距离寻找敌人的压力转成对战道具。下面的生命、寿命、墨耗、追敌与攻击参数均为 TideInk 自定，并非 Nintendo 数值。模型、圆润眼睛／鳍／四足动画和 SVG 图标为本地原创，没有复制 Splatoon 素材、模型或代码。

## 玩法

准备页选择“墨仔伙伴”。按住右键查看实际胶囊投掷轨迹和首次碰撞点，松开投出；E 快投。投掷预览遇真实墙、薄楼板、地形或格栅停止，低资源／动作锁时变红；只能在当前道具规则允许时施放。

| 参数 | 当前值 |
|---|---|
| 墨耗／独立冷却 | 45 墨水／18 秒 |
| 生命／寿命／上限 | 45 HP／12 秒／每人一只 |
| 本地检测／地面速度 | 8m／4.2m/s |
| 扑击范围／前摇／伤害／后摇 | 1.2m／0.22 秒／18／0.38 秒 |

投掷 → 落地搜寻 → 追敌 → 范围与音效预警 → 扑击 → 再次搜寻。没有看见敌人时短暂保留最后看见的位置；随后在通道无遮挡时跟随主人。墙、楼板和敌方墨雾阻断发现；远处潜墨目标隐藏，实际开火或声呐可暴露。扑击结算时重新检查距离和遮挡，可以退开或隔墙躲避。

它使用真实 `CharacterBody3D` 胶囊与重力；不会穿墙、跨楼层锁定或传送追敌。本批为短距离地面追击，没有绕复杂拐角的全图寻路或攀高能力。

敌方主武器／爆破可击毁；机器人优先处理更近的可见敌方伙伴，射击高度对准小胶囊，伞弹使用相同小目标高度。实际喷枪与伞弹反制已验证，八种武器的反制手感尚未逐一人工验收。无友伤，扑击共用角色护盾、天赋、伤害来源与实际 CPU 涂墨账本，不写名单、队伍人数或 UI 计分。HUD 显示实际 HP、寿命、状态与剩余 CD；受击显示主人姓名和“墨仔伙伴”。

主人死亡、寿命结束、落水、过度远离主人或终场时移除伙伴；独立道具冷却跨死亡和重摇保留。它不改变任何武器专属大招。

## 投放提示

| 道具 | 提示与规则 |
|---|---|
| 墨水手雷 | 按住右键显示抛物线、弹跳和预计爆点；爆点圈为当前配置的爆炸半径；松开施放，E 快投 |
| 墨仔伙伴 | 按住右键显示胶囊弧线与首次碰撞点；松开投出，E 快投 |
| 感应墨雷 | 人形状态显示脚下放置点与 2.2m 触发半径 |
| 声呐／补给盒 | 显示实际脚下部署点与小范围定位圈；圈不是探测或补给范围 |
| 跳跃信标 | 显示实际左右择优落位点，要求己方墨面和完整站立净空 |
| 回声诱饵／信息墨雾 | 显示准星选定且通过实际范围／遮挡／落地检查的位置；墨雾圈为 3m 名义半径 |

六类放置道具保持 E／右键立即使用。浅黄色为有效且可施放；红色为无效地形、冷却、缺墨或动作锁。所有圈与标签经过深度测试，不透墙；暂停、死亡、潜墨和结算隐藏提示。地形无效时只显示红色小点，不画误导性的范围圈。

手雷预测和实际飞行共用无副作用的发射与碰撞步进查询，包含玩家速度继承、24m/s² 重力、地面／墙面弹跳以及触地引信。预计爆点反映当前静态地形、瞄准、速度和固定物理步长；移动后会更新，未来地形或帧步长变化可能改变结果。范围圈表达名义半径，实际伤害仍服从距离与遮挡。

预测最多 300 段，约每 0.08 秒更新；有限 `MultiMesh` 绘制轨迹。放置预览直接复用实际施放的只读查询，既不耗墨、开始冷却，也不部署、伤害或涂墨。
