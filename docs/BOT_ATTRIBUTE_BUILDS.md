# AI 配点与战术名单

双方 AI 入场时按自己的主武器和已选天赋随机分配属性。原来八属性完全等概率，可能让高耗墨武器缺乏续航、机动武器偏向无关属性；现在用不同抽取权重形成倾向，每个属性仍有机会出现。玩家直接加点和均匀属性 ROLL 保持原规则。

## 武器倾向

| 主武器 | 优先方向 |
| --- | --- |
| 喷溅枪 | 生命、奔跑，兼顾墨量与续航 |
| 滚筒 | 生命、潜泳与省墨 |
| 蓄能狙 | 墨量、省墨、回墨 |
| 三弦墨弓 | 省墨、回墨与墨量 |
| 爆破枪 | 省墨，兼顾生命、墨量和奔跑 |
| 双持喷枪 | 奔跑、潜泳与生命 |
| 回旋飞镖 | 奔跑、省墨与回墨 |
| 推进挡墨伞 | 生命、墨量与续航 |

权重决定抽到某属性的概率，不保证每次得到固定流派。某项达到 8 级后会退出本次抽取池，剩余点继续分配给其他属性。未知武器使用通用权重，未知天赋不追加修正。

七个特色天赋再调整倾向：逆境反击偏生命与回墨，命中回复偏生命与省墨，敌墨潜游偏生命与奔跑，翻墙加速偏奔跑与生命，残墨引爆偏生命与副武器冷却，极限省墨偏省墨和回墨并降低墨量权重，涂地充能偏充能与续航。均衡不追加修正。敌墨潜游不因潜泳加点提高其固定敌墨速度；极限省墨的绝对墨量触发线保持原规则。

## 公平预算与整局锁定

双方机器人使用玩家实际已花点数，最多 20 点、单项最多 8 级，收益上限与递减公式相同。玩家只花 7 点时双方 AI 也各得 7 点；不加隐藏攻击、射速或额外护盾。分配不回血、不补墨、不清道具冷却，开战／复活仍由既有路径恢复到属性后的上限。

初次入场只 ROLL 一次。死亡、复活、局内主副武器重摇不会重新分配属性，因此换武器后仍保留入场时的配点。CPU 墨格与计分、玩家选择复活点、跨死亡道具冷却和整局天赋锁定保持原约束。

## Tab 显示

按住 Tab 打开三列战术总览：中央保留实时地图，我方／对方各列独立演员卡片。卡片显示真实主武器图标、亮色姓名、武器与情报状态，以及「20 点 · 生命8 / 跑速8 / 回墨4」形式的摘要；玩家自己的卡片使用队色描边。采用项目已有的 Latin／中文字体与浅色文字，暗层降低背景干扰，1v1 只保留双方各一张卡片。图标与样式在构建时缓存，刷新复用。

摘要是已用点数及等级最高三项，不是即时资源或增益百分比；未分配时明确显示「0 点 · 未分配」。同级按八属性的固定顺序显示。敌方当前生命和位置继续由情报系统限制，公开属性不创建情报标记。松开 Tab 关闭总览及暗层，隐藏时不计算摘要。

`core/attribute_catalog.gd` 定义抽取权重、分配和摘要；`abilities/tidewater_attributes.gd` 保存整局快照，`ui/tidewater_hud.gd` 只读显示。专项 `check_bot_attribute_builds.gd` 覆盖随机分布、预算／等级／别名负例、双方实际 5v5／1v1、死亡和换武器锁定、真实资源上限、情报遮蔽及两尺寸 Tab 输入。检查与实机记录见 [本批验收](../render-evidence/bot-builds-2026-10-10/summary.md)。

源码实施批次按功能记录，没有递增版本号；随后用户要求编译 App，已在保持版本字串的情况下按生产提交 `25fa67e` 导出，并通过实际 PCK 的配点与两尺寸 Tab 检查，见 [应用验收](../render-evidence/app-build-2026-10-10/summary.md)。当前 App 的构建身份以 [工作状态](COORDINATION.md) 为准；随机分布检查和受控原生输入不等于真人平衡、自然整局策略或长期性能验收。
