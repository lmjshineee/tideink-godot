# TideInk · 完成度路线

更新：2026-10-05。当前为单机玩家＋机器人；八主武器、十道具、八天赋、七地图已有可玩闭环。阶段证据见 [当前状态](COORDINATION.md)，通过自动检查不等于真人手感或审美已经验收。

## 1. 美术与信息表达

先统一人物、场景、墨水和特效的视觉质量：轮廓、脸部、动作、材质、光照、双方颜色的可辨识性。墨水要有湿润高光和厚薄层次，远处保持稳定；受击、弹道、爆炸预警应清楚且少遮挡准星。

本批已改水润墨水、敌墨数字提示及 HUD 整数误差。下一项可独立验收：人物运动和落地动作在普通跑动、潜墨、爬墙、八武器持握时的完整原生对照；正式替换人物模型仍需用户视觉评审。

## 2. 对局手感与平衡

按实际对局调整八武器的射程、出手节奏、墨耗和专属大招频率，并对照不同技能水平。重点看平均交战距离、充满大招所需时间、发动后的有效收益、死亡／换装是否产生捷径，避免只根据单个伤害数值判断强弱。

本批敌墨降至 2 HP/s，潜游天赋 0.6 HP/s；上限、非致命规则与敌墨减速保留。下一项可独立验收：同地图同 AI 的分组真人配装试玩，记录实际大招频率和墨量中断。

## 3. 地图与机器人

已有高台交战横移、三档难度和复活后跳跃，需要在全部地图自然对局中检查路径、坡道、高低落点、出生区通行和双方是否公平。再发展涂地／支援／交战的队伍策略，使用真实可见情报。

下一项可独立验收：逐地图双方出生到主要高台的可达路线，以及自然 5v5 中受阻等待时间；有卡住位置再补对应回归。

## 4. 稳定性与交付

建立可重复的长时原生样本，检查帧时间尖峰、内存增长、温度、重复重开、暂停恢复和保存的设置。继续绑定源码与实际 arm64 应用收据；源码检查、受控画面、自然对局、真人试玩、温度和导出分别记录。

联网是后续独立大项，需要新的权威状态、同步与断线恢复设计；当前 5v5 不代表在线十人。新增模式或地图应有单独的体验目标与验收条件。
