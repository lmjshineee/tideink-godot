# 三件装备与能力槽 · preview.23

本批实现用户选择的头饰／衣服／鞋子能力配置，准备页点「装备 · 12槽」进入编辑器。每件一个主能力、三个附加槽，全部免费开放，可逐槽选择、清空或单独 ROLL。整套配装 ROLL 同时重摇主武器、天赋、副武器与十二槽；固定套装的主／副／大招关联继续保留。

[Nintendo 装备入门](https://splatoon.nintendo.com/en/news/beginner-basics-for-splatoon-3-choosing-the-right-gear/)说明原作每件装备有一个主能力和最多三个附加能力。本项目采用这个结构，以下能力池、点数公式与上限是本地设计，不宣称完整还原原作，也不新增服饰模型、商店、经验刷槽或付费抽取。

## 实际能力

| 能力 | 同类满配上限 | 生效路径与范围 |
| --- | --- | --- |
| 奔跑加速 | +12% | 人形跑速、干地墨形；不突破射击／爬墙／特殊动作上限 |
| 潜泳加速 | +12% | 己方墨地潜泳；敌墨潜游仍为天赋原速 |
| 主武器省墨 | −18% | 八主武器主射、蓄力、甩墨、滚刷；不改变滑步、护伞维持／推出或副武器耗墨 |
| 回墨加速 | +20% | 玩家与机器人自然回墨；不增加容量、不缩短等待、不增加补给量 |
| 大招充能 | +15% | 实际有效新增涂地的充能；己方重涂、墙面和大招自身涂地仍不给充能 |
| 副武器冷却 | −15% | 新施放的冷却，包括回溯锚开始冷却时；不缩短已有剩余冷却 |

装备不改变生命、伤害、攻击间隔、护盾量或单轮伤害封顶。默认均衡仍为 132 HP／110 墨量／基础移动 ×1.05；上一批普通近四轮／远五轮、弓需追击与满蓄狙精准一击的击倒门槛保留。其他条件天赋仍独立起效，装备加成与天赋／逆风支援乘算，效果页面显示装备本身的实际百分比。

## 权重、递减与公平

主能力提供 10 点，附加能力提供 3 点；三件同类满配为 57 点。空槽不提供点数。对于同类总点数 `p`，先限制到 0—57，再按 `上限 × (p / (p + 20)) / (57 / 77)` 求加成。第一份能力收益较明显，继续堆同类的边际收益递减；57 点恰好达到表中上限。各类能力独立合计，不重复修改基础配置。

默认装备为空槽，以保留既有基线。进入入场动画时，机器人按玩家启用的同一槽位位置／点数预算随机能力：玩家三件全满则双方各 57 点；只启用头饰主槽和一个附加槽则双方各 13 点；空槽保持相同。机器人种类可以不同，但不能获得额外槽位。入场至开战只生成一次，之后不会随主／副重摇或死亡变化。

## 生命周期和输入

- 能力配置独立于一个整局天赋。入场动画与直接开战都会锁定；改阶段、回准备页或点击旧 UI 不能绕过锁定。
- 玩家选择的装备在地图／模式切换、结算重开时通过本次会话配置保留；不承诺退出 App 后的磁盘存档。
- 编辑能力和单独装备 ROLL 不回血、不补墨、不充能、不清冷却。死亡配装重摇仍只改变主／副；角色装备和天赋固定，复活仍由玩家选点并确认。
- 编辑器打开时，Enter 选择焦点能力；数字键不触发主武器切换；Esc 只关闭编辑器。完成按钮返回准备页，不自动开战。
- 960×540／110% UI 与 1280×720 使用同一原生布局。能力说明和汇总显示百分比，副武器冷却与主武器详情读取实际参数。

## 权威与验证

`core/gear_catalog.gd` 定义规范形状、六能力、点数和随机；`abilities/tidewater_gear.gd` 拥有各角色的配置快照与点数缓存；`tidewater_perks.gd` 在现有真实移动、耗墨、回墨、充能与冷却路径叠加。`ui/gear_editor.gd` 只调用合法编辑 API，不保存第二份战斗状态。查询返回副本；损坏会话值归一化，非法编辑整笔拒绝。

`check_gear_abilities.gd` 包含损坏配置、额外槽、未知能力、快照别名、负／超限点数、递减、随机覆盖、资源／冷却保持、双方预算与整局锁定负例，并验证真实移动积分器、八主武器扣墨、玩家／机器人回墨和充能、实际副武器施放。`verify_gear_abilities.gd` 使用原生鼠标／Enter／Esc、窗口缩放、地图规则重载和实际省墨射击。自然整局的装备快照由 `measure_native_match.gd --gear-roll` 另行核对。

规则、受控原生、自然自动对局和实际 App 导出分别记录；它们不代替真人平衡、外观审美或长期温度验收。证据进入 `render-evidence/gear-abilities-2026-10-09/`。
