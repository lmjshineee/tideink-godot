## 原作与本地选择

[Nintendo 武器入门](https://splatoon.nintendo.com/en/news/beginner-basics-for-splatoon-3-choosing-the-right-weapons/)说明每个武器套装包含一个主武器、一个固定副武器和一个特殊武器。副武器可以是攻击或支援装置；特殊武器通过涂墨积攒。原作不是同时携带数个副武器、临场切换的道具背包。

[Nintendo 装备入门](https://splatoon.nintendo.com/en/news/beginner-basics-for-splatoon-3-choosing-the-right-gear/)说明头、衣、鞋各有一个主能力和最多三个附加能力。因此原作可以叠多种装备能力；preview.22 保留一个整局天赋，preview.23 曾加入三件／十二能力槽，preview.24 按用户反馈改为直接属性加点，详见 [当前属性规则](ATTRIBUTES_CHARACTERS.md)。上述入门资料发布于 2024 年，不作为最新数值补丁规格。

[Nintendo 对战规则入门](https://www.nintendo.com/en-gb/News/2024/December/Beginner-basics-for-Splatoon-3-the-ins-and-outs-of-playing-online-2645154.html)区分全图涂地战与争夺指定区域的占地模式。preview.22 曾实现对应的两种本地规则，当前中央区域模式已移除；地图区域、80%/40% 门槛、罚分算法与时长是本地设计，不宣称逐项还原原作。

## 当前生效数值

基础资产生命仍为 120；默认“均衡”天赋提高为 **132 生命、110 墨量、跑／潜泳／干地墨形速度 ×1.05**。它不增加攻击伤害。其他天赋保留各自代价与条件，机器人使用均衡时获得相同加成。

以下为均衡 132 HP、无盾、无临时增伤／易伤目标，命中实际胶囊且部位倍率统一 ×1：

| 主武器 | 有效伤害 | 当前门槛与代价 |
| --- | --- | --- |
| 喷溅枪 | 34 → 26.52 | 近距四发、末端五发；0.1 秒间隔、0.92 墨／发 |
| 双持喷枪 | 每弹 18，一轮两弹 | 近距四轮、末端五轮全中；0.16 秒间隔、1.6 墨／轮；滑步另耗墨 |
| 滚筒刷 | 接触 95；甩墨 105→22 | 接触／近甩需要追击；0.5 秒接触间隔，0.22 秒前摇、0.62 秒甩墨间隔、9 墨；墨滴共享预算 |
| 蓄力狙 | 未满 28→约 71；满蓄 115 | 满血均衡剩 17 HP；1.15 秒蓄力、0.40 秒释放恢复、2.5→18 墨；射线 11→24 m／半径 0.04m，最终伤害上限 118 |

| 三弦墨弓 | 每箭 17→35；三箭满蓄 105 | 全中后剩 27 HP；0.4 秒半蓄／0.8 秒满蓄、2.5→8.5 墨；爆裂共享 40，整轮原始 120／最终 130 上限 |

四发喷枪理想首次至第四次命中约 0.3 秒，双持四轮约 0.48 秒。它们只是零失误的配置下限，实际还包含弹道、距离、散布、回避与失误；不是经真人验证的 TTK。

## 配装与随机

固定套装使用本地已有能力，主武器决定副武器与专属大招：

| 主武器 | 固定副武器 |
| --- | --- |
| 喷溅枪 | 墨水手雷 |
| 滚筒刷 | 护盾 |
| 蓄力狙 | 脉冲声呐 |
| 爆破枪 | 感应墨雷 |
| 双持喷枪 | 回声诱饵 |
| 回旋飞镖 | 回溯锚 |
| 三弦墨弓 | 信息墨雾 |
| 推进挡墨伞 | 接力补给盒 |

名称以实际 UI 资产标签为准。自定义模式仍可独立选择八种主武器、十一种副武器与八天赋；大招属于主武器，不能独立抽选。点击一个副武器自动转为自定义，避免玩家的选择被下一次套装同步覆盖。

开战前的 ROLL 一次重摇主武器、天赋、副武器，避免返回完全相同的组合。套装模式按主武器匹配副武器，自定义模式独立抽选。开战后天赋与完整随机按钮锁定；死亡配装重摇只改变主／副，不改变天赋、不重置已使用道具的冷却。

## 涂地限制与历史中央争夺（已移除）

CPU 墨格是唯一归属和计分权威：

1. 不可涂材质不留墨，直接面涂墨 API 也不能绕过限制。
2. 墨墙可以留墨、显示并攀爬，但不增加涂地面积积分或大招充能；被遮蔽格同样不给奖励。
3. 全图涂地战按有效可涂地面／坡面覆盖率判定。
4. 中央争夺只统计黄色框内、所在表面高度附近的有效格。区域由本地表面、双方可达导航与覆盖格约束选取，十九种布局均检查；框外有效地面仍可提供个人涂地与大招充能。
5. 一队区域覆盖达到 80% 取得控制，降至 40% 以下失去控制。控制方从 100 倒数；失去控制产生本次推进量 50% 的向上取整罚分。夺回后先清罚分，再继续倒数。
6. 到零提前胜利；时间到时落后／持平的控制方可加时，直到失控或取得领先。比较最佳倒数，再比较区域覆盖；完全持平显示平局。
7. HUD 显示倒数、罚分与当前控制方；结果页显示最佳计数。视觉框与 UI 仅读取规则，不写墨格。

## 验证边界

规则测试覆盖实际弹丸／箭／射线、三类角色路径、满蓄和追击、墙／楼板／护盾、临时增伤与共享上限。新增测试覆盖配装随机范围、整局锁定、跨死亡冷却、区域反例、十九布局及 UI 输入。原生和实际导出证据见本批验收。

机器人自动输入与受控截图可以证明规则可运行，不能替代真人平衡、审美或长期温度验收。preview.21 的长帧原因仍未完成诊断；本批不据此宣称性能问题已经解决。

## 属性点与生存

未加点均衡基线仍为 132 HP／110 墨量；生命 8 级最高为 155.76 HP，近距喷枪 34 需要五次准确命中。本批狙击调整为 115／最终上限 118，因此未加生命的健康角色也能存活。生命点提供额外追击容错，同时不能用于机动和效率；不是额外攻击加成。装备能力槽已移除，详见 [八属性与预算](ATTRIBUTES_CHARACTERS.md)。
